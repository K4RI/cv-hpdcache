NAME
       bcg_execute - execute a BCG file as an SUT or TC

SYNOPSIS
       bcg_execute -io [-gate|-partial|-total] file [-sut|-tc [-tgv]] [-seed N] [-timeout N] [-version] graph[.bcg]

DESCRIPTION
       bcg_execute  simulates the IOLTS graph.bcg, reading inputs from standard input and writing outputs to the standard output, one transition label per line.  The       IOLTS is stored in the bcg(LOCAL) format; inputs are defined by the file provided with the mandatory -io option.

BCG FORMAT
       See the bcg(LOCAL) manual page.

OPTIONS
       The following options are currently available:

       -angelic
              Use angelic completion for unspecified inputs.  This option is not meaningful in combination with option -tc.  Not a default option.

       -io [-gate|-partial|-total] file
              Specify the inputs of the specification (outputs of the tester) according to the match file file.  Mandatory option.

       -seed N
              Use N as seed for the random number generator.  Not a default option.

       -sut
              Interpret inputs/outputs as specified by the file provided with the mandatory -io option.  This is useful to execute a system under test.  Default  op‐
              tion.

       -tc
              Interpret inputs/outputs opposite to the specification in the file provided with the mandatory -io option.  This is useful to execute a test case.  Not
              a default option.

       -tgv
              Make the hypothesis that the test case has the form of those generated by TGV, i.e., (1) each label carries a suffix indicating whether it is an inputs
              (";  INPUT")  or an output ("; OUTPUT"), taking the view point of the test case ; (2) the label of each transition leading to a verdict state carries a
              second suffix with verdict (" (INCONCLUSIVE)" or " (PASS)").  With this option, option -io is not mandatory (and ignored).  This option is  only  mean‐
              ingful in combination with option -tc.  Not a default option.

       -timeout N
              Use N as the number of seconds for the quiescence detection timeout.  The default timeout value of 0 deactivates quiescence detection.

       -version
              Display the version number and stop.  Not a default option.

EXIT STATUS
       Exit status is 0 if everything is alright, 1 otherwise.
